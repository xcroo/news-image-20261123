A one-page newspaper front page for Monday, November 23, 2026: "The Global Herald".
Five lead stories anchor the page: COP31 ending without a climate pact in Antalya;
the Pentagon limiting military ties with Canada; Iran strikes widening across the
Gulf, with Bahrain demanding UN action and oil tankers hit in the Strait of Hormuz;
a magnitude 6.7 earthquake shaking Peru's Andes; and Mexico capturing FBI
most-wanted cartel boss 'El Chapo Isidro' after deadly firefights in Sinaloa.
Two smaller items round out the front page: the Indonesia factory fire (3 dead,
36 missing) and South Korea's education chief quitting over an AI cheating scandal.
The image is the entry itself; this program simply delivers it to the output
directory unchanged.

## Run it

```sh
python3 main.py
```

The program copies the bundled `entry.png` to the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`) as `entry.png`, verifying the copy
is non-empty and byte-identical in size to the source.
